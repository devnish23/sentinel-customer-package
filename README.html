Minifra Sentinel · Customer Portal Package

Sentinel Customer Portal
v3.0.1

Installer-ready package — Windows & Linux. Includes Customer Portal, Knowledge Base, and full documentation. No internet required after setup.

17 Portal Pages 14 KB Articles Windows + Linux Auto-configures as OS Service Offline-capable

⚡ Quick Install

Windows (run as Administrator)

setup.bat

Linux (with root for systemd service)

chmod +x setup.sh
sudo ./setup.sh

The script asks for your Hub API URL, port, and company name — then builds and starts the portal automatically. That's it.

📦 What's in This Package

🖥 Customer Portal (React App)

17-page web portal: Dashboard, Agents, Recordings, Alerts, Policies, Configuration (15 tabs), License, Hardware Binding, License Migration, Vault, Exports, Chain of Custody, Audit Logs, Health Check, Packages, Admin/RBAC, Knowledge Base.

📚 Knowledge Base (14 Articles)

Full offline KB covering: installation, agent troubleshooting, license activation, recording engine, antivirus exclusions, export workflow, hardware migration, firewall setup, upgrades, tamper alerts, compliance, and support bundles.

⚙️ Windows Installer

setup.bat — builds the portal, patches in your Hub URL, and registers as a Windows Scheduled Task that auto-starts on boot. uninstall.bat to remove.

🐧 Linux Installer

setup.sh — installs as a systemd service (with root) or starts with nohup (without root). Manages start/stop scripts in scripts/.

📋 Requirements

RequirementDetails
Node.jsv20 LTS or later — only needed during setup/build, not at runtime
Minifra Hubv3.0.0 or v3.0.1 running and reachable

BrowserChrome 115+, Edge 115+, Firefox 115+ (for portal users)
NetworkPortal machine must reach Hub API — TCP 8080 or 8443

🔧 Reconfigure

Run setup.bat / setup.sh again at any time to change the Hub URL, port, or company name. Answer y to "Re-configure?" when prompted. The portal is rebuilt and restarted automatically.

# Change config manually
config\sentinel.config     ← Windows
config/sentinel.config     ← Linux

# Template with all options
config\sentinel.config.example

🔑 API Integration

To connect your backend: Edit portal/src/lib/api.ts. The base URL comes from window.__SENTINEL_CONFIG__.apiBaseUrl (set by setup script) or VITE_API_BASE_URL env var. Add auth headers in the req() function.

// portal/src/lib/api.ts — add auth header here:
headers: {
  "Content-Type": "application/json",
  "Authorization": `Bearer ${localStorage.getItem("sentinel_token") ?? ""}`,
  // Add your own header here, e.g.:
  // "X-API-Key": import.meta.env.VITE_API_KEY,
}
