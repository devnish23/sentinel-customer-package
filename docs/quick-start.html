Quick Start Guide

Version 3.0.1 · Updated 2026-06-01
⏱ ~30 minutes total

This guide gets you from zero to a fully operational Minifra Sentinel deployment. You will install the Hub, register one Agent, activate your license, and access the Customer Portal.

Prerequisites

Before you begin, ensure you have:

  • A Windows Server 2019+ (or Windows 10/11) machine for the Hub — minimum 8 GB RAM, 100 GB disk
  • One or more Windows 10/11 machines for Agents — minimum 4 GB RAM, 20 GB disk
  • Your Minifra license file (.lic) — provided by your Minifra contact
  • Node.js 20 LTS installed on the machine where you run this package
  • Firewall access: TCP 8080 (or 8443) open between Agents and Hub

Step 1 — Install the Hub

1

Download Hub Installer from Customer Portal → Packages

File: MinifraHub-Setup-3.0.1.exe — run as Administrator on your Hub machine.

MinifraHub-Setup-3.0.1.exe /DIR="C:\Program Files\Minifra\Hub"

The installer registers MinifraHub as a Windows Service and starts it automatically.

2

Verify Hub is running

curl http://localhost:8080/health

Expected: {"status":"HEALTHY","version":"3.0.1"}

Step 2 — Install the Customer Portal

3

Run the installer (Windows)

setup.bat

When prompted, enter your Hub API URL (e.g. http://192.168.1.10:8080/api/sentinel). The script builds the portal and sets it up as a Windows Scheduled Task that auto-starts on boot.

4

Run the installer (Linux)

chmod +x setup.sh && sudo ./setup.sh

Running as root installs a systemd service. Without root it starts in the background with nohup.

5

Open the Customer Portal

Browse to http://localhost:3000 (or the port you chose). You should see the Minifra Sentinel Customer Portal dashboard.

Step 3 — Activate Your License

6

Generate Machine ID (for hardware binding)

Customer Portal → Hardware Binding → click Generate Machine ID. Copy the hash shown.

7

Import your license file

Customer Portal → License Management → Import License File → select your .lic file.

📋 Air-gapped / offline? Click "Activate Offline" instead. See KB-003 for the challenge/response steps.

Step 4 — Deploy Your First Agent

8

Download Agent Installer

Customer Portal → Packages → Minifra Agent Installer v3.0.1 → Download.

MinifraAgent-Setup-3.0.1.exe /HUB_URL=http://192.168.1.10:8080
9

Verify agent appears in portal

Customer Portal → Agents. Within 60 seconds the new agent should appear with status ONLINE.

⚠ Agent still offline after 60s? Check firewall (TCP 8080) and agent logs. See KB-004.

Step 5 — Configure and Run a Health Check

10

Run full health check

Customer Portal → Health Check → Run All Checks. All items should show PASS.

You're Live

Agents are recording, evidence is flowing to the Vault, and the Customer Portal is operational. Next steps:

  • Create recording Policies (Customer Portal → Policies)
  • Set up Alerts and SMTP notifications (Configuration → Alert Config)
  • Add RBAC users with appropriate roles (Admin / RBAC)
  • Read the Configuration Guide for advanced settings
