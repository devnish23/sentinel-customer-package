Windows Installation

Step 1 — Prerequisites

Install Node.js 20 LTS on the machine where you will run the Customer Portal.

node -v   # should output v20.x.x or later
npm -v    # should output 10.x or later

Step 2 — Run the installer

Right-click setup.bat → Run as Administrator

The script will prompt you for:

  • Hub API URL — e.g. https://192.168.1.10:8443/api/sentinel
  • Portal port — default 3000
  • Company name — shown in portal header
  • Service install — auto-start on boot (recommended: Yes)

Step 3 — Verify

http://localhost:3000   # Customer Portal should load

Linux Installation

chmod +x setup.sh
sudo ./setup.sh          # with root: installs systemd service
./setup.sh               # without root: starts with nohup
Tip: Run as root to install as a systemd service that auto-starts on reboot.

Manage the service

sudo systemctl status  minifra-customer-portal
sudo systemctl restart minifra-customer-portal
sudo systemctl stop    minifra-customer-portal

Reconfiguring

Run setup.bat (or setup.sh) again at any time. When prompted "Re-configure? (y/N)" answer y to change the Hub URL, port, or company name. The portal will be rebuilt and restarted.

Uninstalling

uninstall.bat    # Windows
./uninstall.sh   # Linux

Source files in portal/src/ are preserved. Only the build artefacts and service registration are removed.

Proxy / Network Notes

  • If your network requires a proxy, set HTTP_PROXY / HTTPS_PROXY env vars before running setup.
  • If Hub uses a self-signed TLS certificate, you may need to set NODE_TLS_REJECT_UNAUTHORIZED=0 — see config/sentinel.config.example.
  • The portal proxies all /api/ requests to the Hub URL — no CORS configuration needed on the Hub.
