Configuration Guide

Version 3.0.1 · Updated 2026-06-01

The Configuration page in the Customer Portal has 15 tabs covering every aspect of the deployment. Access it at: Customer Portal → Configuration.

Tab 1 — Initial Setup Required on first install

FieldDescriptionExample
Customer NameYour organisation nameAlpha Manufacturing
Site NameThis deployment's site/locationSingapore DC
Environment Typepilot / production / DRproduction
Hub URLFull URL of the Hub APIhttps://192.168.1.10:8443
Vault Storage LocationPath on Hub machine for evidenceC:\minifra\vault
NTP SourceTime server for clock syncpool.ntp.org

Click Validate Configuration after saving — all checks should show PASS.

Tab 2 — Hub Config

FieldNotes
Hub Bind IP0.0.0.0 to listen on all interfaces; or specific IP
Hub PortDefault 8080 (HTTP) or 8443 (HTTPS)
Log LevelINFO for production; DEBUG for troubleshooting only
TLS EnabledStrongly recommended for production deployments
Admin API SecretRotated via "Rotate Admin Secret" button — store securely

Tab 3 — Agent Config

FieldNotes
Heartbeat IntervalDefault 30s. Lower = faster detection but more traffic
Offline ThresholdDefault 90s. Agent marked OFFLINE after this with no heartbeat
Update Channelstable (default), beta, rc
Tamper DetectionAlways leave ON in production
Uninstall ProtectionPrevents agent uninstall without Hub authorisation

Tab 4 — Recording Config

⚠ OpenCV is a processing layer only — NOT a capture engine. Always use Auto, Desktop Duplication API, Windows Graphics Capture, or Screenshot Fallback as the capture method.
FieldRecommended
Capture MethodAuto (system selects best available)
FPS5 (general), 10 (compliance/legal)
Resolution1280x720 (general), 1920x1080 (compliance)
Chunk Duration30s (default) — shorter = finer granularity, more files
Watermark EnabledON for legal evidence
Timestamp OverlayON for audit trail

Tab 5 — Policy Config (Retention)

FieldNotes
Evidence Retention (days)Minimum 90 for most compliance frameworks
Export Approval RequiredMust be ON for SOC 2 / ISO 27001 compliance
Self-Approval BlockedMust be ON — prevents single person approving own exports
Chain Verification RequiredON — verifies hash chain before export is downloadable

Tab 8 — Alert Config (Notifications)

Configure where alerts are sent:

  • Email (SMTP) — enter SMTP server, port, sender address
  • Telegram — enter Bot Token + Chat ID
  • Slack / Webhook — enter webhook URL

Use the Send Test Email / Send Test Telegram buttons to verify delivery before saving.

Tab 12 — Security

SettingRecommendation
MFA EnabledON for all production deployments
Session Timeout15–30 minutes for high-security environments
Evidence EncryptionAlways ON
Self-Approval PreventionAlways ON
Tamper DetectionAlways ON
Secure UninstallON — agent cannot be removed without Hub auth

Tab 15 — Config Audit History

Every configuration change is logged here with: Change ID, Module, Field, Old Value, New Value, Changed By, Timestamp, Reason, Approval status. Use Export Audit Report for compliance evidence.
