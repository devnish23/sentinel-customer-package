Customer API Contract

Base path: /api/sentinel/customer · Version 3.0.1

All endpoints require the Authorization: Bearer <token> header in production. The token is obtained from your identity provider (configured in Hub). In local/dev mode with no auth configured, the header is optional.

Dashboard

GET/customer/dashboardSummary stats for the portal home page
Response: { totalAgents, onlineAgents, offlineAgents, recordingActive,
           alertsToday, tamperEvents, licenseStatus, vaultHealth,
           storageUsageGb, storageCapacityGb, pendingExportApprovals,
           recentActivity: [{time, event, type}],
           health: { services: [{name, status, note}] } }

Agents

GET/customer/agentsList all agents
Response: [{ id, hostname, ip, os, version, status, recordingStatus,
            tamperStatus, assignedPolicy, lastHeartbeat, department }]
GET/customer/agents/:idAgent detail with logs and heartbeat history
Response: { ...agent, heartbeatHistory, logs, localStorageUsedGb, localStorageCapacityGb }
POST/customer/agents/:id/push-configPush config to a specific agent
Response: { ok: true, message }

Recordings

GET/customer/recordingsList recordings
Response: [{ id, agentId, hostname, startTime, endTime, durationSec,
            fileSizeBytes, status, chunkCount, chainStatus, fps, resolution }]
GET/customer/recordings/:id/chunksRecording chunk list with hash chain
Response: [{ chunkId, fileName, fileSize, sha256Hash, previousHash, captureMethod, chainStatus }]

Alerts

GET/customer/alertsAll alerts
Response: [{ id, agentId, hostname, type, severity, status, message, createdAt, assignedTo }]
POST/customer/alerts/:id/acknowledge
Response: { ok: true }
POST/customer/alerts/:id/assign
Body: { assignedTo: "user@company.com" }  →  Response: { ok: true }
POST/customer/alerts/:id/close
Response: { ok: true }

Policies

GET/customer/policies
Response: [{ id, name, type, status, approvalStatus, assignedAgents, lastModified, modifiedBy }]
POST/customer/policiesCreate policy
Body: { name, type, description }  →  Response: { id, ...policy }
POST/customer/policies/:id/approve
Response: { ok: true }
POST/customer/policies/:id/assign
Response: { ok: true }

Configuration

GET/customer/configuration
Response: { customer, site, environment, hubUrl, hubIp, hubPort, vaultPath,
           retentionDays, tlsEnabled, certPath, logLevel, fps, resolution,
           captureMethod, watermarkEnabled, emailEnabled, smtpServer, ... }
POST/customer/configurationSave configuration (any subset of fields)
Body: { module: "Hub", ...fields }  →  Response: { ok: true, message }
POST/customer/configuration/validate
Response: { valid: true, checks: [{ name, status }] }

License

GET/customer/license
Response: { id, customerId, siteId, productEdition, agentLimit, activatedAgents,
           hubLimit, vaultLimit, startDate, expiryDate, gracePeriod,
           hardwareBindingHash, status, features, activationHistory }
POST/customer/license/importImport license file (multipart or base64 body)
Response: { ok: true, message }
POST/customer/license/activate-offline
Body: { activationBlob: "base64..." }  →  Response: { ok: true, message }

Hardware Binding

GET/customer/hardware-binding
Response: [{ id, hostname, machineId, bindingHash, status, boundAt }]
POST/customer/hardware-binding/generate
Response: { machineId, hostname, bindingHash, status: "GENERATED" }

Exports & Chain of Custody

GET/customer/exports
Response: [{ id, caseId, reason, status, requestedBy, approvedBy, createdAt, downloadCount }]
POST/customer/exports
Body: { caseId, reason, agentIds, dateFrom, dateTo }  →  Response: { id, ...export }
POST/customer/exports/:id/approve
Body: { user: "reviewer@company.com" }
Response: { ok: true }
Error 400: "Self-approval not allowed" if same user as requester
GET/customer/chain-of-custody/:exportId
Response: { exportId, createdBy, approvedBy, chunks: [{...hash chain}], manifest, status }
POST/customer/chain-of-custody/:exportId/verify
Response: { verified: true, status: "VALID", verifiedAt, message }

Vault, Audit, Health, Packages, RBAC

GET/customer/vaultEvidence entries
Response: [{ id, agentId, hostname, recordingId, type, size, hash, status, createdAt }]
GET/customer/auditImmutable audit log
Response: [{ id, timestamp, user, role, module, action, target, result, ip }]
GET/customer/health
Response: { lastRun, services: [{ name, status, latencyMs, note }] }
POST/customer/health/runRun health checks now
Response: { lastRun, services: [...updated results] }
GET/customer/packages
Response: [{ id, name, type, version, releaseDate, checksum, status }]
GET/customer/rbac
Response: [{ id, name, email, role, status, lastLogin }]
POST/customer/rbac/users
Body: { name, email, role }  →  Response: { id, ...user }
POST/customer/rbac/users/:id/disable
Response: { ok: true }
